# Research Methodology and Experimental Protocol

This directory contains the formal mathematical and clinical justifications for the experimental design:
- `failure_aware_hybrid_methodology.md`: Formulation of uncertainty, entropy, margin, and pairwise disagreement meta-features.
- `statistical_validation_protocol.md`: Descriptive EDA, Kruskal-Wallis, Chi-square, and paired bootstrap testing protocols.
- `responsible_ai_and_fairness.md`: Subgroup fairness across age and socioeconomic strata, calibration curves, and LIME false-negative audit.
