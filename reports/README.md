# Research Reports and Evidence Package

This directory contains formal project audits, factual summaries, and manuscript alignment dossiers:

- `00_EXECUTIVE_PROJECT_SUMMARY.md`: Executive summary of problem, methodology, findings, and contributions.
- `PROJECT_FACTS_FOR_CHATGPT.md`: Self-contained research dossier formatted as an authoritative source for manuscript writing.
- `MANUSCRIPT_GAP_ANALYSIS.md`: Section-by-section comparison mapping baseline paper sections to available evidence.
- `SOURCE_EVIDENCE_INDEX.csv`: Traceability matrix linking all reported values to specific source files and cells.
- `AUDIT_FINDINGS.md`: Reconciled technical resolutions of all empirical evaluations.
- `METRIC_CONTRADICTION_RESOLUTION.md`: Scientific reconciliation of accuracy vs. recall trade-offs.
